Principais ajustes:

Variáveis Vercel necessárias para IA:

IMPORTANTE: após alterar variáveis na Vercel, faça novo Redeploy.

Antes de publicar:
npm install
npx prisma generate
npx prisma db push
npx prisma db seed
npm run build

Se a IA retornar erro de cota, verifique o faturamento/créditos da API OpenAI; ChatGPT Plus e API são cobranças separadas.
